# Your logos

Drop any brand marks you want available for thumbnails and graphics here — your own logo, and the
logos of products/tools you talk about (and have the right to use).

- Transparent **PNG** is best.
- Name them clearly (e.g. `mybrand-icon.png`, `mybrand-wordmark.png`).
- The thumbnail generator can bake these in as `extra_refs` per concept.

Only add marks you have usage rights to. This folder ships empty on purpose.
