# Your face references

Drop **4–8 photos of your own face** in this folder. The thumbnail generator passes every image
here to lock *your* identity into generated thumbnails.

**Good refs:**
- Varied angles, expressions, and lighting (neutral, smiling, serious, surprised).
- Square-ish crop, face filling most of the frame.
- Clear and sharp — no heavy filters, no sunglasses, no group shots.
- `.png`, `.jpg`, or `.webp`.

**Naming** doesn't matter, but something like `01_neutral.png`, `02_smile.png` keeps it tidy.

You only need these if you generate thumbnails (long-form YouTube). Short-form usually skips
thumbnails, so this can stay empty until you need it.
