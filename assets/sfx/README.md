# assets/sfx/ — your sound-effects library

This folder is the SFX library the editing skills reach for during timeline sound
design (whooshes, clicks, risers, impacts under graphics and cuts).

It ships **empty** to keep the download small. Two ways to fill it:

1. **The SFX pack** — if you received a separate download link with this system
   (a ~140 MB pack of 123 clips), unzip it straight into this folder.
2. **Your own clips** — drop in any `.wav`/`.mp3` sound effects you like working
   with. Descriptive filenames help Claude pick the right one ("whoosh-soft.wav"
   beats "sfx_014.wav").

Nothing in the core pipeline requires this folder — rough cuts, captions, music,
and renders all work without it. It's only used when you ask for sound design.
